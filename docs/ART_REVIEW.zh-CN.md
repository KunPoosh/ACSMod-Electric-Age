# 电气时代素材接入检查

日期：2026-09-27。对象：项目根目录 `electric_age_art/`，按 ART_SPEC v1.2 检查。[English](ART_REVIEW.md)

**结论：六种模块素材满足首轮开发与接入需求，未发现需要返工的模块素材问题。完整 UI 尚缺五张图标；真实游戏加载与表现仍待验证。** 本轮没有修改原始素材、运行交付 Lua 脚本、安装 MOD 或实现玩法。

## 独立检查结果

- 读取六个 exports 目录中的 121 张生产 PNG：全部可解码、RGBA、具有透明背景、尺寸符合对应本体/部件/横排动画/组合展示规格；没有空白 PNG。当前生产图 alpha 为硬边透明/不透明，没有半透明缩放边缘。
- 独立解析八份正式 Aseprite 源文件（六个 source.aseprite，另有推进桨叶与火炮炮管），均为 32 位 RGBA，共 47 个图层。确认原尺寸画布、帧数、100 ms 帧时长及可编辑分层数据；没有调用 Aseprite 应用加载测试。
- 共 445 项静态断言通过，其中 45 项源层/源帧与 PNG 像素比较。另核对动画横排切片、正常/受损差异、状态非空且互异、火炮/电池/线圈塔的文档化组合，以及放电锚点在正常/受损电极中均有像素。此数字是素材静态检查，不是玩法测试数量。
- 已目视检查六模块总览、各模块状态/损伤预览。造型、像素密度、色调与当前规格一致；无烘焙人物、选中框或全塔装甲壳等明显冲突。正式游戏缩放、与邻接模块组合后的可读性仍需实机观察。
- 本地可复查证据：[检查脚本](../build/asset-review/audit.py)、[详细结果与文件 SHA256](../build/asset-review/audit.json)。两者在忽略的 build 目录中，不是产品代码或发行资产。

## 缺项与后续验证

**需要后续补齐的 UI 美术：**五张 16×16 PNG，即 electricity、weapon_overload_off/on、propulsion_overload_off/on。资产 README 已明确本轮未制作。这不阻碍电网及模块接入开发，但完成正式按钮外观前需要补齐。

**符合现阶段交付边界、无需先返工：**推进器受损桨只有停转草图，没有受损运动循环。运行时可以先将受损本体与完整工作桨组合，不能把受损停转完整预览当成所有受损状态；若要表现“损坏但仍转动的桨”，后续再补。bump、碎片、完整残骸、炮口闪光和闪电端亮闪均属已允许后续补充/程序处理的内容。

**由接入代码完成：**图集与定义打包、状态选择、炮管旋转/后坐/镜像、外伸绘制顺序、线圈塔无装甲判定、人员路径、模块形状及存储。现有透明像素不自动定义碰撞洞或 canOccupy；线圈塔无装甲也不能只靠不画装甲贴图实现。炮管已给出可靠锚点，但完整射界旋转尚未游戏验证。

**闪电效果：**沿已讨论的程序折线、亮芯/光晕和短暂淡出方向实现。攻击先结算并保存节点路径，表现随机源独立；渲染不重新选点或重复伤害。当前交付的固定电极与锚点足够支持该实现，不要求美术再画整条闪电。

当前结论是“可进入开发接入”，不是“已经在游戏中验收通过”。
