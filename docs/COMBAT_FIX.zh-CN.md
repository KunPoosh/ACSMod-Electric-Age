# dev.4：部署浮力、过载入口、闪电射程圈与雷声

2026-09-27。[English](COMBAT_FIX.md)。本轮按用户要求只编译打包，没有运行测试或启动游戏；以下是实现内容和待实测预期，不是实机验收结论。

## 修改

- **部署电浮力**：只在 PlaceShipTool 的部署高度查询中，将电浮晶舱视为额定输出；预览线使用同一计算。不修改实际电网状态、不耗煤/电、不产生过载损伤。原版损坏、人员等运行资格仍生效；纯原版船不改。战斗中的供电、停机和过载倍率保持实际结算。部署预览不保证开战后有足够电力持续维持高度。
- **两个过载开关**：从顶部全局栏移至底部舰船面板，文字显示“武器过载”“动力过载”及开/关/部分状态。普通选舰支持多选；直接操控针对当前操控舰船，并为电力条和按钮预留高度。无对应设备的一侧不可用；指令未就绪时禁用，原指令消耗与请求状态机制不变。普通面板在返回导航/正常选舰状态时显示。
- **闪电外圈**：仅修正电气时代闪电在原版 360° 射界路径中的外圈 Y 坐标，使其以实际炮口为圆心，随镜头和缩放移动。首击射程仍为 320，实际攻击逻辑未改。
- **低音量雷声试配**：使用游戏自带 thunder5，层音量 0.25，通过原版成功开火后的 fireSound 通路播放；分叉不额外播雷声。未复制或修改游戏音频。约 1.49 秒的素材仍需试听多塔齐射效果，后续可只调整 content/devices.json。

## 更新与实测

退出游戏，用 `Electric-Age-0.1.0-dev.4.jar` 替换 `Setup.cmd` 同层 mods 内的旧版本 JAR，不要并存相同 MOD ID 的多个版本。无需另装音效或贴图。Acbric 配套资源更新时会保护玩家修改；如果手动改过旧版解包配置，留意框架报告的冲突，新雷声配置可能因此没有自动替换。

1. 用仅装电浮晶舱的正常配员船重新部署，比较高度限制和升限线，再用混合原版浮力的船对照。开战后断电仍应失去实际电浮力。
2. 普通选舰、直接操控各看底部按钮；分别开关两类过载，观察指令消耗和冷却后的重新可用；多选检查“部分”状态。
3. 选中闪电武器后上下移动镜头、缩放和翻转船体，外圈应保持以炮口为中心。实际射程仍按此前规则。
4. 听单塔开火和多塔齐射，反馈声音是否太响、太轻或拖尾。没有命中目标的无效开火不应重复刷雷声。
