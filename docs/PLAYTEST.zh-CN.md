# 电气时代 dev.4 实测手册

[English](PLAYTEST.md)。首轮使用单人自定义战斗，验证基线为游戏 1.2.15.3、JDK 21；框架版本和检查范围见 [TESTING](../TESTING.zh-CN.md)。

dev.4 本轮只编译打包，未启动测试；请先看[本轮修复与实测项目](COMBAT_FIX.zh-CN.md)。过载文字按钮位于底部舰船面板，普通选舰和直接操控均可使用。

## 安装与建造

1. 关闭测试实例，把 `Electric-Age-0.1.0-dev.4.jar` 放入 Acbric 的 `Setup.cmd` 同层 `mods`；升级时移走同 ID 旧 JAR。
2. 从 Acbric 正式入口启动，确认 Java MOD 电气时代已启用，并在原版 MOD 列表启用其配套资源，按提示重启/重载。首次纹理生成可能较慢。
3. 使用独立舰船编辑器或全科技自定义战斗。六设备名称以“电气时代”开头，使用原版机械加工奖励资格。
4. 发电机需要煤仓与人员，火炮需要弹药与人员，推进器/浮力/闪电也需要操作员。保留驾驶、宿舍及通行布局；闪电塔在顶部安装，不覆盖装甲。

使用独立测试实例与测试船。包中的 `Electric Age Test Ship.json` 是探针集成布局，有通行/补给警告，仅供观察后自行调整，不是完成平衡或航行优化的船包。构建没有自动覆盖玩家运行副本。

## 观察顺序

| 场景 | 预期 |
| --- | --- |
| 正常供电 | 发电机 220 kW；推进/浮力/炮/闪电额定分别为 40/60/60/40 kW，共 200 kW；闲置武器也用电，发电机空载也耗煤 |
| 电池 | 2000 kJ、充电上限 50 kW、放电上限 200 kW；先保额定，再重启与过载；不同时充放电 |
| 缺电 | 电池接替；耗尽后降频、按最低功率比例逐个离线；恢复时需完整额定冗余才能重启 |
| 两个过载开关 | 武器/动力可同时开启；开关都消耗原版指令；缺电保留请求，恢复后再次尝试 |
| 过载损伤 | 仅实际超过额定时，每秒损失最大 HP 的 1%，直接伤模块；允许原版起火/殉爆和普通维修 |
| 降落/断裂/俘获 | 降落停用动力和浮力；断裂各留自身电量并继承开关；俘获清除开关 |
| 闪电 | 射程 320、精度高、无弹药、基础装填 4 秒；首击标称 100 单点爆炸伤害，近邻表面目标分叉，无飞行弹丸 |

原版资源区新增电力条：黄色实际用电、红色在线欠额定、灰纹为具备运行资格但因缺电离线的需求、绿色剩余可用供电；底部细槽显示电量及充放电方向。模块贴图区分关机/额定/降频/过载/受损。建造统计为额定用电/发电、电池容量（断电支撑时间）、武器/动力/全舰过载需求。

完整战役连续战斗、补给路线、自动结算回写、实际网络同步与长时间人工交战仍待验收。原生序列化和补给入口已自动检查，但不等同整条战役闭环通过。

反馈请附版本、布局、步骤与实例日志，优先观察装填、动力、状态贴图和电力条。
