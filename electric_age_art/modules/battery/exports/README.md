# 蓄电池导出说明

32×32 px，2×2 格，16 px/格。源文件单帧、5 个绘画层，无动画标签。所有 PNG 保持 32×32 RGBA、左上原点 (0,0)，透明画布未裁切。

## 文件与叠合顺序
1. `body.png` **或** `body_damaged.png`：正常/受损结构母层，互斥。包含罐体、框架、汇流排、端子、检修面板和未点亮的指示槽。
2. `charge_level.png`：完整五段灯条叠层，供接入时按实际电量显隐/裁取；不烘焙任何容量数值。
3. `flow_charging.png` **或** `flow_discharging.png`：左/右方向形状相反的指示，互斥；无充放电流时两者均不显示。

`battery.png` 是正常结构 + 五段灯条、方向灯不亮的完整展示图；`battery_damaged.png` 为相同指示下的受损展示图。二者用于默认查看，不表示游戏中电池必定满电，也不要再往它们上面重复叠加灯条。

`layers/` 按 Aseprite 图层名保存同一套母层，便于作者检查。源文件默认隐藏 Structure_Damaged、Flow_Charging 和 Flow_Discharging，显示 Structure_Normal 与 Charge_Level。

## 电量与方向
- 五段灯条区域见 `anchors.txt`。每段 2×2 px，水平间隔 1 px。
- 仅提供一个完整灯条母层；接入方可以整段显隐，或按选定 UI 规则裁取。五段不定义物理电池分组、储能容量、分段阈值或余额计算。
- 充电箭头朝左，指向罐体；放电箭头朝右，指向外部。两者使用同色，靠形状辨别方向；本版本不含文字或数字。
- 镜像接入时应根据语义选择/重定位方向指示，不能把整图镜像后的箭头方向当作已验证的充放电映射。
- 受损与电量/电流方向相互独立，不把“受损”画成必定空电或关机。
- 不为蓄电池创建 rated/derated/overload 状态，不制作全图百分比序列或无意义动画帧。
