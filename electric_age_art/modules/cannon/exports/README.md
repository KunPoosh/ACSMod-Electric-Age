# 电动装填大炮导出说明

本体48×32 px（3×2格），独立炮管48×16 px，16 px/格。使用常规弹药，电气部分表现为装填电机、减速传动、推弹杆及控制指示；炮管没有电磁导轨或能量发射光效。

## 源稿与叠合
- ../source/source.aseprite：单帧、9层、48×32，本体及供弹/装填部件。
- ../source/barrel.aseprite：单帧、2层、48×16，正常/受损炮管互斥。
- 所有单独部件保留各自完整透明画布与左上原点，不裁切。

按以下顺序组合：
1. body.png 或 body_damaged.png（48×32）：炮座、弹架框、装填轨、电机、传动及控制盒。
2. ammo_rack.png（48×32）：三枚备用弹外观。
3. round_tray.png（48×32）：托盘上一枚待装炮弹。
4. loader_ram.png（48×32）：推弹杆的静止后退姿态。
5. barrel.png 或 barrel_damaged.png（48×16）：放在本体坐标(24,4)，默认朝右。
6. mount_over.png（48×32）：固定炮耳外侧盖，覆盖炮管接合处。
7. state_rated.png / state_derated.png / state_overload.png（48×32）：选择一种电动装填状态，关机全隐藏。

正常/受损是替换关系；身体损伤和炮管损伤可独立选择。弹药与推弹杆均独立留层，后续按装填/弹药状态控制；画出的数量是外观，不定义库存容量、装填量或供弹规则。

## 运行状态
- 关机：控制灯熄灭，机械保持静止；待装弹仍可保留，不把无电等同无弹药。
- 额定：蓝白双指示。
- 降频：较小暗蓝单指示；机械速度由接入方控制。
- 实际过载：装填电机局部热斑及更亮的指示。显示依据是实际过载，不是指令开关。
- 炮管上不叠加这些电气状态。火炮发射和装填时序尚未接入。

cannon.png / cannon_damaged.png 是72×32完整额定展示；stopped.png / stopped_damaged.png 为完整关机参考。它们已经合成，不重复叠加部件。72×32是含外伸炮管的展示画布，不代表占地变成4.5×2格。

## 炮管与后坐交接
炮轴在本体为(32,12)，在炮管图为(8,8)；炮口在炮管图为(47,8)，默认在本体为(71,12)。详见 anchors.txt。

生产素材只交独立静态炮管，由程序驱动后坐。../previews/recoil-fit.aseprite 与 recoil-fit-8x.gif 是4帧叠合示意：炮管相对默认位置的X偏移为0、-3、-2、0 px，100 ms/帧；固定炮座盖、装填件不动。该示意无击发、弹药消耗或装填循环逻辑，不作为生产发射动画，也不定义射速或后坐物理参数。

已核对上述姿态中炮管与待装炮弹/推弹杆无像素穿插。未验收旋转射界、镜像或任意后坐行程。炮口闪光为规格可选项，本轮保留给接入时尝试原版效果，没有空白占位闪光图。
